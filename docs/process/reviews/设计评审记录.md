## 评审结论

- **结论**：通过。
- **核心取舍**：M4 追求「闭环可演示 + 可复现」，牺牲检索效果换取轻量；效果类指标（F1 / Recall@K）留待 M5 换向量召回后统一评测。

## 主要决策

| 主题 | 决策 | 理由 |
|---|---|---|
| 检索 | TF-IDF（sklearn `TfidfVectorizer`）+ 关键词召回 | 无向量库 / 模型下载依赖，评测可复现 |
| 状态解析 | 规则 + mock LLM：RETAIN / UPDATE / SUPERSEDE / CONFLICT | 规避外部 API 不可复现问题 |
| 记忆存储 | 结构化 JSON（`schema_version 0.1`）+ 原始证据溯源 | 可导出、可回溯、可验收 |
| 前端 | 记忆列表 / 过滤 / 证据溯源 / 关系时间线 / 问答面板 | 覆盖「浏览、溯源、状态解析过程展示」必做项 |
| 评测 | 功能验收（场景 / pytest / 证据 / 导出）先行；批量评测接口先 501 占位 | 中期先保证功能正确性 |

## 遗留风险

- TF-IDF 对语义近义、词序 / 语法 / 否定、词形 / 拼写 / 缩写不鲁棒，M5 换向量召回 + 查询扩展缓解。
- CONFLICT 自动消解逻辑尚为规则版，M5 结合图记忆深化。
