# 版本记录（Changelog & Version Tags）

> 对应课程要求：版本控制中的 *version tag*。
> 每个里程碑交付物定稿后打 tag，并在此记录版本变更。

## 版本命名规范

- 格式：`v<major>.<minor>-m<milestone>`
  - `major`：里程碑定稿状态（`0` = 草稿，`1` = 定稿）
  - `minor`：该里程碑内的迭代次数
  - `m<milestone>`：对应里程碑（`m1` / `m2` / `m3` / `m4` / `m5`）
- 示例：`v0.1-m1`（M1 初稿）、`v1.0-m1`（M1 定稿）
